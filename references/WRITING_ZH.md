# 對外中文文案下限（2026-08 定案）

台灣基線不只管設定，也管**對外文字品質下限**。對外＝會給客戶、合作方、公眾看的任何文稿（提案、報告、信件、網站、社群、圖卡文字）。

## 1. 中文稿交給中文母語模型

- **對外中文文案一律由中文母語模型撰寫、修改或擴寫**（現階段：DeepSeek V4 Flash；日後換中國模型，原則不變）
- 自己（美系模型）**不准硬寫對外稿**：中文輸出容易出現譯腔、排比、樣板、不自然的成語堆疊
- **自己不定稿**：寫完先過中文母語模型加寫／改寫，才交付
- 只改幾個詞不算過；要真的讓中文母語模型重寫
- 分析、推理、程式、內部溝通不受此限；只限**對外中文文案**

### 實務注意（DeepSeek）

- DeepSeek V4 Flash 預設 thinking 開著；API 只讀 `content` 會拿到空字串，要取 `reasoning_content` 或呼叫時關掉 thinking（`thinking.type=disabled`）
- 不要用 Pro 檔做日常加寫（貴；Flash 已夠）

## 2. 禁用的寫作痕跡

- **寫作術語不出現在交付物**：起、承、轉、合、鋪陳、伏筆等（使用者明確要求除外）
- **中文破折號（——）**：對外文稿禁用；長停頓改用句號或重排句子
- **AI 排比／樣板**：三連排比、對仗句、口號式結尾
- **emoji 濫用**：正式文稿不用 emoji 當裝飾（社群依平台習慣另論）

## 3. 溝通習慣（繁體中文、台灣）

- **結論先講**：先講結果／建議，再講過程
- **講完整的詞與句子**：不要簡寫（「桌機」要講「桌上型電腦」這類讀者可能不懂的縮寫）
- **數字用阿拉伯數字**（123，不是一二三）
- 三段式回報：做了什麼／結果／下一步

## 4. 檢查清單

- [ ] 對外文稿已由中文母語模型加寫／改寫
- [ ] 無「起承轉合」等寫作術語
- [ ] 無中文破折號
- [ ] 無排比／樣板／口號式結尾
- [ ] 結論先講；數字用阿拉伯數字；無難懂簡寫
